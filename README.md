# 의상 테마 일괄 관리 · Gacha Outfit Manager

대상: **Marinara Engine 2.5.0 / Gacha Forge 1.8.12** 개인 확장.

## 1.3.0 업데이트

- 기존 설정 버튼의 배치·너비·클릭 동작을 바꾸지 않습니다. 의상 테마 설정에서는 기존 버튼 아래 별도 영역에 톱니바퀴를 배치합니다. 테마 라이브러리에서는 도구 모음의 별도 항목으로 표시합니다.
- 관리창과 설정 아이콘의 입력 이벤트가 게임 버튼으로 전달되지 않도록 분리했습니다. Escape 처리는 관리창 안에서만 작동합니다. 창을 닫으면 설정 아이콘으로 키보드 초점을 돌려줍니다.
- 같은 테마 목록을 반복 복사하지 않고, 내용이 달라진 영역만 다시 그립니다. 체크박스를 선택해도 목록 전체를 재생성하지 않습니다. 세계별 사용 개수 계산도 한 번 만든 ID 집합을 재사용합니다.
- 첫 열기의 중복 목록 요청을 제거하고, 목록 조회만 할 때는 게임 화면을 다시 불러오지 않습니다.
- 브라우저 탭이 숨겨진 동안에는 정기 화면 탐색을 건너뜁니다. 전체 화면 표시와 기존 보관함 형식은 유지합니다.
- 저장소 루트의 manifest.json과 JS 파일을 그대로 실행합니다. 별도 설치나 컴파일은 필요하지 않습니다.

## GitHub에서 설치·업데이트

마리나라 개인 확장의 GitHub 가져오기에서 다음 저장소 주소를 입력하세요.

https://github.com/lemonpie601/Gacha-Outfit-Manager

기본 브랜치 `main`의 루트에 manifest.json과 실행 파일을 배치했습니다. 확장 이름과 실행 방식은 이전 ZIP과 동일합니다. **기존 확장을 삭제하지 말고 해당 확장의 업데이트·연결 기능으로 가져오세요.** 업데이트 후 마리나라에서 변경된 코드를 검토하고 승인해야 실행됩니다.

## 1.2.1 업데이트

- 가챠포지 전체 화면에서도 설정 아이콘으로 관리 팝업을 열 수 있도록 팝업을 전체 화면의 실제 화면 트리 안에 배치합니다.
- 전체 화면 전환·해제와 게임 화면 재표시 때 기존 팝업을 다시 연결합니다. 열려 있는 팝업과 선택 상태를 유지합니다.

## 1.2.0 업데이트

- 플로팅 버튼을 없앴습니다. **의상 테마 설정의 톱니바퀴**를 누르면 관리 팝업이 열립니다.
- 의상 테마 라이브러리 화면의 가져오기·내보내기 버튼 옆에도 같은 톱니바퀴를 배치합니다.
- 게임이 설정 화면을 다시 그려도 버튼이 다시 붙으며 중복 생성하지 않습니다. 확장을 끄면 추가한 아이콘과 스타일을 제거합니다.

## 1.1.0 업데이트

- 관리 버튼과 열린 창은 **현재 가챠포지 화면이 보일 때만 표시**합니다. 다른 앱 화면으로 이동하면 창과 대화상자를 닫습니다.
- 왼쪽 메뉴, 넓은 테마 목록, 전체 설명 패널로 화면을 나눴습니다. 작은 화면에서는 테마 이름을 누르면 설명 패널이 열립니다.
- 일괄 작업 버튼은 테마를 체크한 뒤 아래에 나타나며, 선택한 항목에 가능한 작업만 표시합니다.
- 세계별 적용과 내보내기는 왼쪽의 접을 수 있는 메뉴에 모았습니다. 기본 목록은 활성·보관함을 합친 전체입니다.
- **이전 확장을 삭제하지 말고 같은 이름으로 ZIP을 다시 가져와 업데이트하세요.** 기존 보관함을 유지하려면 확장 기록을 삭제하지 않아야 합니다. 변경된 코드에 대한 검토 후 실행은 다시 필요합니다.

## 설치

1. 마리나라에서 **설정 → 애드온 → 외부 확장**을 엽니다.
2. **파일 가져오기**로 `gacha-outfit-manager.personal-extension.zip`을 선택합니다. ZIP을 풀지 않아도 됩니다.
3. 가져온 확장에서 요청 권한과 코드를 확인하고 **검토 후 실행(Review and Run)**을 누릅니다.
4. **가챠포지 → 의상 테마 설정**에서 **기존 버튼 아래 ⚙**을 누르세요. 의상 테마 라이브러리 화면에서도 상단 ⚙으로 열 수 있습니다.

이미 사용하던 외부 확장 가져오기 메뉴를 이용하세요. 확장은 가져오기만으로 자동 실행되지 않으며, 이 파일을 위한 코드 승인과 활성화는 앱 화면에서 해야 합니다.

## 502개 테마를 한 번에 관리하기

**의상 관리 → 추천 502개 보관함에 추가**를 누르세요. 현재 게임 라이브러리에 같은 제목과 설명으로 들어 있는 테마는 건너뛰고, 나머지를 **보관함**에 추가합니다. 기존 파일을 다시 200개씩 나눌 필요가 없습니다.

보관함에서 검색하거나 체크박스로 선택한 뒤 **선택 활성화**를 누르면 게임 라이브러리로 들어갑니다. 활성 칸이 부족하면 먼저 활성 탭에서 일부를 **선택 비활성화**하세요. 공간이 부족한 항목을 조용히 버리지 않습니다.

## 버튼별 동작

| 기능 | 동작 |
|---|---|
| 새 테마 | 제목과 설명을 입력해 비활성 보관함에 추가합니다. |
| JSON 가져오기 | `{ "version": 1, "themes": [{ "title": "이름", "desc": "설명" }] }` 또는 테마 배열을 보관함으로 가져옵니다. 한 번에 최대 2,000개, 파일 최대 2MB입니다. |
| 검색 결과 전체 체크박스 | 현재 검색·상태 조건에 맞는 항목 전부를 선택합니다. 화면의 ‘더 보기’ 뒤에 있는 항목도 포함됩니다. |
| 선택 비활성화 | 먼저 사본을 확장 저장소에 보관하고, 선택한 테마를 게임의 공용 라이브러리에서 제거합니다. 모든 세계에 영향을 줍니다. |
| 선택 활성화 | 보관된 테마를 게임 라이브러리에 다시 넣습니다. 예전 ID를 참조하던 세계는 새 ID로 연결합니다. 사용자가 이미 해제한 세계에는 임의로 다시 추가하지 않습니다. |
| 선택 삭제 | 활성 테마를 공용 라이브러리에서 제거하고 사본을 확장 휴지통으로 보냅니다. 비활성 테마는 보관함에서 휴지통으로 이동합니다. |
| 휴지통 → 보관함 | 삭제한 테마를 비활성 상태로 복원합니다. 이후 필요할 때 활성화하세요. |
| 휴지통에서 완전히 지우기 | 확인 후 선택한 휴지통 사본을 제거합니다. 필요한 항목은 먼저 내보내세요. |
| 선택 테마 적용 / 해제 | 드롭다운으로 고른 세계의 테마 선택 목록에만 추가하거나 제거합니다. 게임 라이브러리에서는 삭제하지 않습니다. |
| 선택 / 전체 내보내기 | 선택한 항목을 일반 테마 JSON으로 저장합니다. 선택이 없으면 활성·보관함 전체를 저장합니다. 휴지통은 제외됩니다. |
| 작업 전 백업 내보내기 | 가장 최근 변경 작업 직전의 게임 라이브러리와 세계별 선택 목록을 저장합니다. 테마는 일반 가져오기로 복구할 수 있습니다. `worldSelections`는 참고용이며 가져오기 시 세계 설정을 자동 덮어쓰지 않습니다. |

## 제한과 저장 위치

- **게임 라이브러리는 최대 200개, 한 세계의 테마 선택은 최대 64개**입니다. 설치된 가챠포지의 제한을 지킵니다.
- 비활성·휴지통 사본은 이 확장의 개인 저장소에 보관합니다. 별도의 개수 제한 대신 저장 용량을 검사하며 약 900KB에서 추가 저장을 멈춥니다. 현재 포함된 502개는 이 범위에서 보관할 수 있습니다.
- 세계에 선택된 테마가 0개이거나 선택한 테마가 모두 공용 라이브러리에서 빠지면 **가챠포지 기본 동작에 따라 테마를 자동 생성**합니다. 선택 해제가 의상 생성 전체를 끄는 기능은 아닙니다.
- 세계별 적용·해제를 직접 저장할 때는 해당 세계에 남은 비활성 ID 참조도 정리합니다. 이후 테마를 다시 활성화해도, 이렇게 직접 변경한 선택 목록에는 임의로 되살리지 않습니다.
- 이미 만들어진 의상 그림을 삭제하는 확장이 아닙니다. 다음 생성에 사용할 테마를 관리합니다.
- 생성 중인 세계가 있으면 변경 작업을 막습니다. 생성이 끝난 뒤 다시 시도하세요.
- 중간 실패 시 완료 개수와 실패 항목을 표시합니다. 먼저 저장한 보관 사본으로 재시도할 수 있습니다. ‘복원 마무리 필요’ 항목은 다시 활성화해 세계 연결을 마무리하세요.
- **확장 자체를 삭제하면 개인 보관함도 잃을 수 있으므로, 제거 전에 전체 테마를 내보내세요.** 다른 브라우저에서 동시에 같은 테마를 수정하는 작업은 피하세요.

## 접근 범위

게임의 테마 화면과 같은 서버 API를 사용해야 하므로 `full_page_access` 권한을 요청합니다. 구현은 고정된 동일 출처 `/api/gacha-forge` 경로와 확장 개인 저장소를 사용합니다. 채팅·모델 설정을 읽거나 외부 서버로 전송하는 기능은 없습니다. 현재 브라우저의 기존 관리자 접근 값이 있으면 게임과 같은 방식으로 동일 출처 API에만 전달합니다.

가챠포지의 원본 `client.js`, `server.mjs`, 앱 설정, 데이터 파일을 직접 패치하지 않습니다. 코드 승인을 우회하거나 외부 확장 허용 설정을 자동 변경하지 않습니다.

## 검증 범위

설치된 1.8.12의 테마 API·세계 설정 저장 형식을 대조했습니다. JSON 가져오기, 전체 묶음 보관, 용량 제한, 삭제 전 사본 저장, 중간 실패, 복원 ID 연결, 세계별 적용, 화면 표시 조건, 목록 수 집계를 자동 테스트로 확인했습니다. `node --test tests/manager.test.cjs tests/ui.test.cjs`로 실행할 수 있습니다.

로컬 웹페이지의 자동 승인 검토가 시간 초과되어 **실제 페이지에서 설치·클릭하는 검증은 수행하지 못했습니다.** 앱 업데이트로 API 형식이 바뀌면 연결 오류를 표시하고 작업을 중단할 수 있습니다.
